# 原生 Vulkan 迁移验收

验收报告根目录：`data/verification/native-migration-20261028/`。2026-10-28 已完成正式替换、旧源码归档和新便携包复验。机器可读总报告为 `acceptance.json`，漏字/插入/重复/混说案例为 `error-cases.json`。

## 运行时和边界

- CrispASR v0.8.45，源码 revision `e58bb48b52cf1fe957c19586297c83a2ed0d9fe4`，GGML revision `e2ae679a563014f46c546ce6c6448e8601e4dea6`。
- Windows x64、Vulkan、通用 CPU 构建；LiveCaptions ABI 1 扩展提供原样上下文、生成预算、实际设备、自动语言和结构体尺寸查询。
- `NativeQwenEngine` 仅持有模型，`NativeBinding` 仅负责 ABI；`Recognizer`、Silero、Smart Turn 和分段策略独立。服务装配拥有模型选择与生命周期，WinUI 不参与推理。
- 原生句子识别仍采用有界窗口重新识别；没有新增模型内部 KV 流式算法。
- 原生模型加载选择 Vulkan 独显并核对实际后端；显式 CPU 可选。GPU 请求实际变为 CPU 时返回错误。
- 依赖日志使用 stderr，JSONL 单独持有 stdout 管道；发布不包含模型、API 密钥和本地记录。
- 固定源码补丁同时修复上游 Windows `CreateFileA/fopen` 的中文路径问题，使用 UTF-8 转 UTF-16 及 `ggml_fopen`。补丁脚本和运行库清单保存源码 revision 与 SHA256。

## 三语质量

公开语料为 Google FLEURS test，CC-BY-4.0，固定 parquet revision `168de341b3db6859a9bac1c50a2ef5e3b47647e0`。按数据集顺序取样，直至每种语言同时满足 30 段和 600 秒。中文 56 段/605.62 秒，英文 63 段/601.14 秒，日文 46 段/602.64 秒。

同一音频输入、贪心解码、512 token 生成预算、逐段语言提示、空上下文。归一化统一为 NFKC、小写和标点转空格；中日文按字符计 CER，英文按词计 WER。每个报告保存参考文本、原始输出、编辑距离、输入 SHA256；差异样本按增加错误数排序。

## 漏句、重复和混说案例

三语独立语料无整段空输出；字符/词删除和插入逐条列入 `error-cases.json`，包含相同输入的旧/新输出与编辑操作计数。这些操作计数不等价于语义级漏句数量。

额外把中文、日文、英文三个公开短样本以 0.5 秒停顿拼成 27.96 秒，自动语言识别表现较差：0.6B 输出重复的 `Evened, evened, evened.`，1.7B 主要保留最后的英语内容。随后以同一拼接 PCM 补测旧 BF16，两型号分别与 Q8 逐字一致。该混说案例属于原有模型限制，不计入独立语种 CER/WER；结果与补测参数保存在 `mixed-reference.json` 及 contracts 报告。
