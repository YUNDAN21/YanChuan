## 无前端复现

在仓库根目录：

```powershell
uv sync --extra endpoint
uv run --no-sync pytest tests/core -q
uv run --no-sync python scripts/verify_library.py
```

自动测试使用替身模型验证协议和边界，不能证明识别准确率。真实验证不启动服务、不打开采集、不播放声音，覆盖中英文单窗口、长文件和 PCM 增量。报告为 `data/verification/core-api-*.json`，记录完整事件、处理时间、实际 GPU 和模型加载次数。

`apps/asr-test/` 单独验证 HTTP、CLI、设备生命周期、混音、归档、范围读取、任务排队和退出释放。已移除网页静态文件及挂载，保留 OpenAPI 文档。桌面服务与进程接口另有独立测试，见 `docs/desktop-api.md`。

## 本次发现并修复的缺口

- PCM 非数值和复数输入现在统一返回 `ASRError(code="invalid_audio")`，不会泄漏 NumPy 转换异常或静默截掉虚部。
- 标准音频对象检查采样率、时长、帧数和静音元数据一致性，避免错误的静音标记跳过真实语音。
- 过小流窗口提前拒绝，避免配置低于最小识别窗口时没有结果。
- CLI 迁移后无前端调用和错误输出有独立测试。

## 仍待验证或实现

当前是分块增量，不是 Qwen 原生流式。RMS 与句子启发式对噪声、音乐及标点质量敏感；日语/混说精度、CER/WER、小时级稳定性、设备时钟漂移、磁盘故障恢复仍待专项验证。翻译、总结、说话人分离与词级时间对齐属于后续范围，不计入本次“当前核心 API 功能完整性”结论。
