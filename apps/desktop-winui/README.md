# 言川 · WinUI 桌面应用

英文品牌名 **YanChuan**，发布程序为 `YanChuan.exe`，安装包使用英文文件名。全新安装的数据目录为 `%LOCALAPPDATA%\YanChuan`；已有 `%LOCALAPPDATA%\LiveCaptions` 时继续使用原位置，不搬移模型、会议或配置。开发入口、Python 包名与内部 C# 命名空间沿用现有路径。

C# / WinUI 3 前端，一个应用提供会议记录主窗口和置顶字幕悬浮窗。界面通过后台客户端访问独立 Python 进程，识别、语义分段、保存与总结由可组合的库完成。

## 启动

```powershell
powershell -ExecutionPolicy Bypass -File .\start.ps1
```

脚本定位仓库根目录，初次创建后端独立 uv 环境，并通过已安装的 Visual Studio MSBuild 构建 x64 免打包应用。后端由 C# 隐藏启动，无需另开服务或占用端口。开发依赖是 .NET SDK 10 和 VS2026 WinUI 工作负载；Windows App SDK 2.1.3 由 NuGet 还原。现有模型使用仓库缓存，不自动下载。

## 操作

- 主窗口选择会议名称、系统音频/麦克风/混合、语言和具体设备，点击右上录制图标开始会议；运行时变为停止图标，结束时保存尾句。导入图标支持 WAV/FLAC，逐段处理，没有总录音时长上限。
- 左侧历史列表重新打开已保存的会议；转写带相对时间范围，右侧按主题显示 Markdown 总结。记录在 `data/meetings/`，底部按钮打开目录。
- 历史会议右侧垃圾桶删除对应会议，确认后永久删除该会议的转写、总结、问答和导出文件。当前录音或总结期间先结束任务再删除；删除当前会议后清空内容，模型、API 配置及外部原始音频保留。
- 名称输入框旁铅笔图标保存当前会议名称，录音中也可修改；历史列表与磁盘导出同步更新。转写和总结右上复制图标分别复制全部内容，底部复制图标合并复制会议内容，均保留时间戳。
- 左侧顶部四个图标依次为字幕、提示词模板、API 配置、识别模型；底部为主题、音频设备，断连时显示重新连接。图标保留键盘焦点和无障碍名称，悬停查看具体功能。界面去掉宣传语和固定保存提示，复制结果仍短暂显示。
- 右上对话图标切换到问答主工作区，占据右侧全部内容空间，返回箭头恢复转写与总结。左侧仍可切换历史会议。圆角输入区底部“默认”菜单统一选择模型和思考强度，支持获取模型列表、关键词筛选与手动输入；悬停显示实际模型。可直接选择已配置连接的模型，问答模型独立于总结保存；思考强度默认不传额外参数，可选关闭、低、中、高、超高和最高，具体档位由模型服务支持。设置只影响下一次提问。
- 输入区使用图标按钮，发送为向上箭头，等待时可点击停止图标；Ctrl+Enter 发送、Enter 换行。问答内容可复制或重试。上下文圆环位于输入区底部，悬停显示输入估算、4096 token 回答预留及上限，点击调整上限，默认 272000 token，可按服务支持改为 1000000。预算由后端估算，不截断会议；前端只展示并丢弃过时响应。
- 总结与问答共用原生 Markdown 组件，支持标题、强调、列表、任务列表、引用、表格、链接及代码块。行内公式可写为 `$x^2$` 或 `\(x^2\)`；独立公式使用 `$$`、`\[...\]` 或 `math/latex/tex` 代码块，支持分式、求和、积分、矩阵和多行对齐。公式本地离线排版并随主题改变颜色，宽公式可横向滚动；复制按钮保留完整 Markdown 和公式原文。代码中的公式分隔符保留原样。
- 右上时钟图标打开自动总结设置，支持启用与 1–120 分钟间隔，首次默认 5 分钟；总结区域的灯泡图标可手动总结。失败保留原检查点，可以重试；没有配置总结服务时仍能转写。
- API 配置入口统一放在左侧，支持新建、复制、改名、删除、保存与取消，以及 Chat Completions、Responses 和 Anthropic Messages；总结区和问答区不显示“默认 API”下拉。总结连接在左侧配置中“保存并使用”。提示词模板提供同样的草稿管理和恢复正文。更换配置仅影响下一任务。
- API 配置的模型框支持“获取模型列表”：使用当前地址、密钥和协议查询，获取后下拉选择或输入关键词筛选，也可继续手动填写。无需先保存配置；修改连接信息或切换配置后丢弃旧列表及迟到结果。
- 左下角太阳/月亮图标切换深浅主题，主窗、字幕窗与编辑框同步，重新启动保留。配置沿用 `data/meeting-settings.json` 和 `data/meeting-appearance.json`，旧密钥和模板直接可用。
- 左侧字幕图标打开置顶小窗，播放/停止图标控制采集。默认最近两行，历史图标展开后最新内容在底部，向上滚动查看更早字幕。短行使用已有语义规则和实际字体宽度，不加载新模型。音频设备沿用主窗选择。
- 字幕窗右下角翻译图标可开启自动翻译，选择中文/日文/英文目标语言、独立 API 或跟随当前 API。提供仅原文、双语（上原文下译文）、仅译文三种显示方式；译文与原语义短行绑定，网络延迟或失败不阻塞识别。配置保存到 `data/caption-settings.json`，首次默认双语、翻译为中文。
- 紧凑字幕文字和窗口默认居中。鼠标移出窗口后背景、边框和控件自动隐藏，只保留白字黑描边字幕；移入时显示背景和操作控件。切换不改变窗口大小或文字位置。展开历史或打开设置时保持背景显示，收起/关闭后恢复自动透明。无需手动观看开关或快捷键。
- 会议、文件导入和独立字幕一次只运行一种，切换前停止当前任务。已加载模型在同一后端中复用。关闭字幕窗停止独立字幕；关闭主窗保存并结束后端。
- 后端断连时可重新连接，随后手动开始任务或打开历史；不会自动开始录音。

日志在 `data/desktop-backend/stderr.log`，分阶段启动计时追加到 `data/desktop/startup.jsonl`。界面状态显示加载阶段，准备期间标题显示当前阶段等待秒数。

## 无声验证

```powershell
dotnet run --project apps/desktop-winui/tests/ClientTests.csproj -- (Get-Location).Path
# 打开真实应用，导入已有测试录音、请求配置的总结 API 并保存验证报告：
& '.\apps\desktop-winui\bin\x64\Debug\net10.0-windows10.0.26100.0\win-x64\YanChuan.exe' --root (Get-Location).Path --verify .\data\samples\asr_zh.wav --report .\data\verification\winui-report.json
```

验证不播放声音、不打开采集设备。`--verify` 创建一条新的验证会议并使用已有总结配置，不覆盖旧会议。协议与库级调用见 [桌面 API](../../docs/desktop-api.md)。

`--verify` 同时验证改名、完整内容导出、真实 API 两轮问答和历史重开，报告保存问答数量及检查点。不会打开设备或试听文件。

## 图标资源

`Assets/AppIcon.png` 为内置 imagegen 生成的透明原图，用户从黑白、墨绿、暖橙示意中选择黑白简约方案：单个黑色圆角气泡内三根白色声波。最终生成提示词为“仅提取对比图左侧黑白图标，保留单个扁平黑色字幕气泡与三根白色圆头声波，移除数字、其他图标、背景与立体效果，透明背景居中”。未使用 CLI/API 生成方式。

`build-icon.ps1` 仅进行尺寸和格式转换，生成包含 16/24/32/48/64/128/256 像素的 `Assets/AppIcon.ico`。EXE 编译资源、主窗和字幕窗使用同一 ICO，品牌区使用 PNG。修改原图后运行此脚本并重新构建。

`--verify-captions <WAV路径> --report <JSON路径>` 是显式无声字幕验证：后台使用文件 PCM 替代设备，走真实增量识别与翻译事件管道，打开字幕窗口，翻译为英语并记录报告。该验证会保存字幕目标语言，测试后可在翻译设置中改回所需语言。

透明窗口使用 [WinUIEx TransparentTintBackdrop](https://github.com/dotMorten/WinUIEx/blob/main/src/WinUIEx/TransparentTintBackdrop.cs)，不是 Acrylic/Mica 模糊背景；WinUIEx 使用 MIT 许可证。

## Markdown 呈现

`Rendering/MarkdownDocument.cs` 负责 Markdown AST 与数学分隔符兼容；`Rendering/FormulaRenderer.cs` 负责本地 LaTeX 栅格化及有界缓存；`Views/MarkdownView.cs` 将 AST 映射为原生控件。该模块不导入后端或拼装 AI 请求。HTML 以文字显示，图片不自动联网加载。Markdig 1.5.0、CSharpMath 0.5.1 和 SkiaSharp 2.88.9 的许可证及字体声明随包放在 `Assets/ThirdParty/`。
