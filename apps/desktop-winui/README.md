# 言川 · WinUI 桌面应用

英文品牌名 **YanChuan**，发布程序为 `YanChuan.exe`，安装包使用英文文件名。全新安装的数据目录为 `%LOCALAPPDATA%\YanChuan`；已有 `%LOCALAPPDATA%\LiveCaptions` 时继续使用原位置，不搬移模型、会议或配置。开发入口、Python 包名与内部 C# 命名空间沿用现有路径。

C# / WinUI 3 前端，一个应用提供会议记录主窗口和置顶字幕悬浮窗。界面通过后台客户端访问独立 Python 进程，识别、语义分段、保存与总结由可组合的库完成。

## 启动

```powershell
powershell -ExecutionPolicy Bypass -File .\start.ps1
```

脚本定位仓库根目录，初次创建后端独立 uv 环境，并通过已安装的 Visual Studio MSBuild 构建 x64 免打包应用。后端由 C# 隐藏启动，无需另开服务或占用端口。开发依赖是 .NET SDK 10 和 VS2026 WinUI 工作负载；Windows App SDK 2.1.3 由 NuGet 还原。现有模型使用仓库缓存，不自动下载。

本机已安装 x64 Windows App Runtime 2.7.0 或更高的 2.x 版本时，脚本将开发版构建到 `bin/installed-runtime/` 并使用系统运行时。后端环境和 NuGet 依赖已就绪时，传入 `-NoRestore` 可直接使用已有依赖构建。

## 操作

- 主窗口使用 Mica 背景和自定义标题栏，左侧为侧栏，右侧为圆角内容层。左下角“设置”打开设置页，按分类集中音频设备、识别模型、AI 连接、提示词模板、外观与窗口及诊断；再次点击或点返回箭头回到会议记录。不可用的按钮只淡化图标，不显示灰色底块。

- 设置页“外观与窗口”可开启“关闭窗口后保留在托盘”，默认关闭并记住选择。开启后点关闭只隐藏主窗口，录音和字幕继续运行；点击托盘图标恢复，右键选择“退出”会保存收尾后退出。

- 模型管理中的“推理设备”可选 GPU（Vulkan）或 CPU；点击“保存并使用”后记住选择。旧配置默认 GPU。先停止当前转写再切换；已加载模型会释放，下一次转写按所选设备重新加载。两种设备共用 GGUF 和分段模型，无需重复下载。

- 工具栏选择音源（系统 + 麦克风/系统声音/麦克风）和语言，具体设备在设置页“音频设备”中选择，未选择时跟随系统默认设备。点击右上“开始录制”开始会议；录制中按钮变为红色“结束会议”，标题下显示录制计时，结束时保存尾句。左侧“导入录音”支持 WAV/FLAC，逐段处理，没有总录音时长上限。
- 会议录音中可直接更改音源下拉框，在系统声音、麦克风和两者之间切换。同一会议继续录音、时间戳连续；切换期间下拉暂时禁用，失败后恢复原选择并显示原因。语言和具体设备 ID 使用开始时的设置。
- 左侧历史列表按“今天/更早”分组，显示开始时间和时长，可按名称搜索，点击重新打开已保存的会议。录音或总结进行中，当前会议标红点“录制中”，其他会议变淡且不能切换。转写左侧显示开始时间（悬停查看时间范围），右侧按主题显示 Markdown 总结；总结和问答中的时间戳以强调色标出，复制内容不变。记录在 `data/meetings/`，工具栏右侧文件夹按钮打开目录。没有内容时两张卡片显示操作提示。
- 悬停历史会议显示“⋯”（也可右键），菜单提供重命名、打开记录目录、复制全部内容和删除会议；对非当前会议重命名或复制时先打开该会议。删除确认后永久删除该会议的转写、总结、问答和导出文件。当前录音或总结期间先结束任务再删除；删除当前会议后清空内容，模型、API 配置及外部原始音频保留。
- 标题旁铅笔图标就地修改会议名称，Enter 或移开焦点保存，Esc 取消，录音中也可修改；未打开会议时为下一场新会议命名。历史列表与磁盘导出同步更新。转写和总结卡片右上复制图标分别复制全部内容，工具栏右侧复制图标合并复制会议内容，均保留时间戳；复制结果在内容上方短暂提示。
- 左侧顶部为“实时字幕”和“导入录音”，底部为“设置”和主题切换，断连时显示重新连接。按钮保留键盘焦点和无障碍名称；历史会议的朗读名称为标题、时间和时长。
- 右上“会议问答”切换到问答主工作区，占据右侧全部内容空间，返回箭头恢复转写与总结。左侧仍可切换历史会议。提问显示为右侧气泡，回答下方一行提供“复制”“加入笔记”，失败时显示原因和“重试”。输入区底部的模型菜单显示当前模型与思考强度，统一选择两者，支持获取模型列表、关键词筛选与手动输入；悬停显示实际模型。可直接选择已配置连接的模型，问答模型独立于总结保存；思考强度默认不传额外参数，可选关闭、低、中、高、超高和最高，具体档位由模型服务支持。设置只影响下一次提问。
- 发送为向上箭头，等待时可点击停止图标；Ctrl+Enter 发送、Enter 换行。上下文圆环位于输入区底部并显示占用百分比，悬停显示输入估算、4096 token 回答预留及上限，点击调整上限，默认 272000 token，可按服务支持改为 1000000。预算由后端估算，不截断会议；前端只展示并丢弃过时响应。
- 总结与问答共用原生 Markdown 组件，支持标题、强调、列表、任务列表、引用、表格、链接及代码块。行内公式可写为 `$x^2$` 或 `\(x^2\)`；独立公式使用 `$$`、`\[...\]` 或 `math/latex/tex` 代码块，支持分式、求和、积分、矩阵和多行对齐。公式本地离线排版并随主题改变颜色，宽公式随可用宽度等比缩放；复制按钮保留 Markdown 结构，并按统一分隔符输出 LaTeX。代码中的公式分隔符保留原样。
- 右上“自动总结”下拉按钮显示当前间隔并打开设置，支持启用与 1–120 分钟间隔，首次默认 5 分钟；总结卡片的“立即总结”可手动总结，进行中底部显示进度。失败保留原检查点，可以重试；没有配置总结服务时仍能转写。
- 在设置页「AI 连接」打开「管理连接」，左侧选择已有配置，右侧修改名称、模型及该连接所需的字段，可以复制、删除或取消编辑。「保存并使用」将选中的配置设为总结连接。提示词模板有独立编辑入口，更换配置仅影响下一任务。
- 「新建连接」在右侧显示服务商预设、通用 API 和本地 Agent。服务商预设会填入名称、地址和协议。通用 API 可分别选择 Chat Completions、Responses 或 Anthropic Messages，编辑时显示所选类型。
- API 配置的模型框支持“获取模型列表”：使用当前地址、密钥和协议查询，获取后下拉选择或输入关键词筛选，也可继续手动填写。无需先保存配置；修改连接信息或切换配置后丢弃旧列表及迟到结果。
- 连接方式选 Codex 或 Antigravity (agy) 可使用本机已登录的 CLI。程序路径留空自动查找并显示实际路径，模型框显示 CLI 的默认项。点击模型框旁的刷新图标获取模型列表，模型留空时跟随 CLI 默认项。总结使用设置页保存的连接，问答在输入栏的模型菜单独立选择。字幕翻译使用 HTTP API。
- Codex 和 agy 问答会逐段显示生成中的正文，结束后呈现 Markdown、公式和核对后的时间戳。问答失败时可用显示的请求 ID 在诊断日志中定位该次调用。
- 左下角太阳/月亮图标或设置页“主题”切换深浅主题，主窗、字幕窗与编辑框同步，重新启动保留。配置沿用 `data/meeting-settings.json` 和 `data/meeting-appearance.json`，旧密钥和模板直接可用。
- 左侧“实时字幕”打开置顶小窗，播放/停止图标控制采集。默认最近两行，历史图标展开后最新内容在底部，向上滚动查看更早字幕。短行使用已有语义规则和实际字体宽度，不加载新模型。音频设备沿用设置页的选择。
- 字幕窗右下角翻译图标可开启自动翻译，选择中文/日文/英文目标语言、独立 API 或跟随当前 API。提供仅原文、双语（上原文下译文）、仅译文三种显示方式；译文与原语义短行绑定，网络延迟或失败不阻塞识别。配置保存到 `data/caption-settings.json`，首次默认双语、翻译为中文。
- 紧凑字幕文字和窗口默认居中。鼠标移出窗口后背景、边框和控件自动隐藏，只保留白字黑描边字幕；移入时显示背景和操作控件。切换不改变窗口大小或文字位置。展开历史或打开设置时保持背景显示，收起/关闭后恢复自动透明。无需手动观看开关或快捷键。
- 会议、文件导入和独立字幕一次只运行一种，切换前停止当前任务。已加载模型在同一后端中复用。关闭字幕窗停止独立字幕；关闭主窗保存并结束后端。
- 后端断连时可重新连接，随后手动开始任务或打开历史；不会自动开始录音。

设置页“诊断”中的“打开诊断日志”打开 `data/desktop-backend/stderr.log`。按请求 ID 可查看 Agent 类型、会议查阅阶段、首段正文耗时、增量数和错误类别。分阶段启动计时追加到 `data/desktop/startup.jsonl`，准备期间窗口标题显示当前阶段等待秒数。

## 无声验证

```powershell
dotnet run --project apps/desktop-winui/tests/ClientTests.csproj -- (Get-Location).Path
# 打开真实应用，导入已有测试录音、请求配置的总结 API 并保存验证报告：
& '.\apps\desktop-winui\bin\x64\Debug\net10.0-windows10.0.26100.0\win-x64\YanChuan.exe' --root (Get-Location).Path --verify .\data\samples\asr_zh.wav --report .\data\verification\winui-report.json
```

验证不播放声音、不打开采集设备。`--verify` 创建一条新的验证会议并使用已有总结配置，不覆盖旧会议。协议与库级调用见 [桌面 API](../../docs/desktop-api.md)。

`--verify` 同时验证改名、完整内容导出、真实 API 两轮问答和历史重开，报告保存问答数量及检查点。不会打开设备或试听文件。

## 图标资源

`Assets/AppIcon.png` 为内置 imagegen 生成的透明原图，用户从黑白、墨绿、暖橙示意中选择黑白简约方案：单个黑色圆角气泡内三根白色声波。最终生成提示词为“仅提取对比图左侧黑白图标，保留单个扁平黑色字幕气泡与三根白色圆头声波，移除数字、其他图标、背景与立体效果，透明背景居中”。未使用 CLI/API 生成方式。

`build-icon.ps1` 将原图转换为含 16/24/32/48/64/128/256 像素的 `Assets/AppIcon.ico`，用于 EXE、窗口和托盘。标题栏和会议助手使用同一份主题化标志，深色主题为黑底白色声波，浅色主题为白底黑色声波。

`--verify-captions <WAV路径> --report <JSON路径>` 是显式无声字幕验证：后台使用文件 PCM 替代设备，走真实增量识别与翻译事件管道，打开字幕窗口，翻译为英语并记录报告。该验证会保存字幕目标语言，测试后可在翻译设置中改回所需语言。

透明窗口使用 [WinUIEx TransparentTintBackdrop](https://github.com/dotMorten/WinUIEx/blob/main/src/WinUIEx/TransparentTintBackdrop.cs)，不是 Acrylic/Mica 模糊背景；WinUIEx 使用 MIT 许可证。

## 笔记

左侧“历史会议”下面直接显示笔记分组列表，展开分组可查看笔记标题，点击笔记打开对应编辑页。笔记标题旁的加号在选中分组下新建笔记；未选中分组时默认使用当前会议组。管理按钮打开分组管理，没有会议也能手动新建分组和笔记。历史与笔记分别滚动，列表刷新保留分组展开状态；摘录、改名和删除会同步更新列表。

编辑页左侧选择分组与笔记，右侧修改标题和正文，保存按钮或切换笔记/关闭窗口时保存；预览开关显示 Markdown 与公式。分组名旁的保存按钮用于重命名分组。删除笔记或整个分组均需确认。

问答回复末尾的“加入笔记”直接保存该条已完成回答到来源会议组，以提问内容作为初始标题。重复点击保留原笔记及后续编辑。笔记保存原始 Markdown；更改分组名称不改变它与来源会议的关联。删除会议保留已收集的笔记，删除笔记不影响原始问答。笔记位于用户数据目录的 `data/notes.sqlite3`。

## Markdown 呈现

`Rendering/MarkdownDocument.cs` 负责 Markdown AST 与数学分隔符兼容；`Rendering/FormulaRenderer.cs` 负责本地 LaTeX 栅格化及有界缓存；`Views/MarkdownView.cs` 将 AST 映射为原生控件。该模块不导入后端或拼装 AI 请求。HTML 以文字显示，图片不自动联网加载。Markdig 1.5.0、CSharpMath 0.5.1 和 SkiaSharp 2.88.9 的许可证及字体声明随包放在 `Assets/ThirdParty/`。

每条回复或总结的文字使用独立的连续 `RichTextBlock`，可跨标题、段落、列表、引用、代码与表格文字拖选。表格以逐行文字和列分隔符呈现，表头加粗；代码使用等宽字体。选中文本后 Ctrl+C、Ctrl+Insert 或右键复制，Ctrl+A 的范围为当前这条回复；不会跨到其他消息。按住鼠标拖选到正文视口上下边缘时缓慢滚动，速度随接近边缘程度增加，上限每秒 140 个逻辑像素，松开后停止。

回复顶部和底部均提供整体复制入口。选区复制和整体复制中的行内公式统一为 `$LaTeX$`，独立公式使用前后各一行 `$$` 包裹 LaTeX；整体复制保留 Markdown 结构与代码块中的字面文本。公式图像参与文本选区，也可单击公式后复制其源码；独立公式使用明确图像尺寸，宽公式随可用宽度等比缩放。

原生选择回归项目为 `tests/SelectionApp/SelectionApp.csproj`：构建 x64 后运行 `SelectionApp.exe <报告路径>`，自动检查跨段部分选择、整条回复、表格单元格、嵌套列表、窄窗口、深色主题和内容替换，保留窗口供鼠标拖选验证。项目不启动模型、后端或音频设备，也不参与正式应用构建与发布。
